# Phase 7.2: Skill And Agent Experience Alignment - Plan

## Goal

Update the Claude-facing surfaces so agents naturally follow the safe bridge
flow and stop relying on manual Bash/git recovery when Codex Bridge already has
the primitive.

## Tasks

1. Rewrite brief guidance.
   - Clarify that brief contents are now delivered to the worker prompt and are
     also persisted for review/check forensics.
   - Show examples with both `--brief` and a real prompt.
   - List valid top-level brief keys and common schema failures.

2. Rewrite resume/iterate guidance.
   - Remove advice that suggests `/codex-bridge:task --resume-last` for normal
     task follow-up.
   - Point incomplete or needs-attention work to `iterate <task_id>` or fresh
     worktree tasks.

3. Reinforce bridge-managed review/verdict/merge.
   - Make manual `git merge subagent/codex/*` an explicit recovery-only path.
   - Add a post-DONE/INCOMPLETE checklist that uses result, review,
     verdict, iterate, and merge.

4. Improve Monitor/artifact forensics docs.
   - Add event vocabulary table and explain task id vs thread id mapping.
   - Document `eventsPath`, `status --json`, `status --watch`, and
     artifact roots without hardcoding stale plugin data directory names.
   - Position bridge as best for multi-file/risky/long-running delegated work,
     not tiny one-shot edits.

5. Refresh generated plugin/skill assets.
   - Run `npm run build`.
   - Verify plugin skill references match source skill references.

## Verification

- `npm run build`
- `npm test`
- `npm run baseline:contracts -- --check`
- Review generated diffs under `plugin/skills/codex-bridge/**`.

## Done Criteria

- P0-03 and P2 docs/positioning issues are reflected in source skill, README,
  command help, and generated plugin surfaces.
