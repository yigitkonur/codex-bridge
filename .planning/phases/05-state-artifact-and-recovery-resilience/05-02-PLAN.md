# 05-02 Plan: Session Log Replay And Registry Artifact Contracts

## Goal

Make append-only session logs and per-task registry artifacts replayable through stable JSON/patch contracts.

## Tasks

1. Add session replay helpers for `.ndjson` and `.events` logs that preserve corrupt lines as structured records.
2. Extend registry helpers to write brief and diff artifacts and read event streams without failing the whole replay on corrupt lines.
3. Wire task and iterate paths to persist brief artifacts; wire completed/dirty task diffs into the per-task registry.
4. Add tests for replay helpers, brief artifacts, diff patches, and corrupt event preservation.

## Deliverables

- `src/lib/session-log.mjs`: `readNdjson`, `readEvents`.
- `src/lib/registry.mjs`: `writeBriefArtifacts`, `writeDiffArtifact`, `readRegistryEvents`.
- `src/codex-bridge.mjs`: registry brief and diff persistence.
- `test/session-log.test.mjs`: session replay tests.
- `test/registry.test.mjs`: brief, diff, and registry event replay tests.

## Verification

- Targeted: `node --test test/session-log.test.mjs test/registry.test.mjs test/bridge-static.test.mjs`
- Full: `npm run build`, `npm run verify:static`, `git diff --check`
