# 04-01 Plan: Packaged Plugin Path Resolution And Generated Assets

## Objective

Make every packaged plugin reference mechanically verifiable: manifest paths, command/agent/hook references, config, scripts, prompts, schemas, templates, and generated surface inventory must all resolve inside `plugin/`.

## Tasks

1. Add recursive plugin-reference tests that scan packaged metadata and text surfaces for `${CLAUDE_PLUGIN_ROOT}/...` references.
2. Assert every plugin manifest path starts as a relative plugin-local path, normalizes under `plugin/`, and points to the expected file type.
3. Extend baseline generated-surface inventory to include packaged plugin metadata, command files, agent files, and plugin skill metadata.
4. Add missing packaged schema inventory for `plugin/schemas/brief.schema.json` if it is intended to ship.
5. Run focused plugin surface and baseline contract tests.

## Acceptance Criteria

- A reference escaping `plugin/` fails tests.
- A `${CLAUDE_PLUGIN_ROOT}` reference to a missing packaged file fails tests.
- Baseline contracts list all packaged plugin metadata/docs surfaces that are part of the installable plugin.
- Existing plugin CLI asset smoke still passes.
