<objective>
Add a single static verification command and a machine-readable generated-surface inventory so maintainers can rebuild both install layouts, run tests, and detect baseline drift from one entrypoint.
</objective>

<threat_model>
- Threat: The new gate claims generated surfaces are synchronized but omits a build-owned output.
  Mitigation: Encode every known generated source/output relationship from `esbuild.config.mjs` in `scripts/baseline-contracts.mjs` and test that the report verifies cleanly.
- Threat: A package script change is not reflected in bundled CLI outputs.
  Mitigation: Run `npm run build` inside `npm run verify:static` and include generated `skill/scripts/codex-bridge.mjs` and `plugin/scripts/codex-bridge.mjs` diffs.
- Threat: The contract script silently passes when package scripts are missing.
  Mitigation: `verifyBaselineContracts()` checks `baseline:contracts`, `verify:static`, `npm run build`, `npm test`, and `baseline:contracts -- --check`.
</threat_model>
