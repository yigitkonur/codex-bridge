<objective>
Classify every dispatched command as read-only or mutating, map mutating commands to success/failure tests, and name baseline gaps where static tests cannot honestly prove live runtime behavior.
</objective>

<threat_model>
- Threat: A new dispatched command is added later without coverage classification.
  Mitigation: Parse `SUBCOMMAND_DISPATCH` from `src/codex-bridge.mjs` and fail `baseline:contracts -- --check` when a command is neither read-only nor mapped as mutating.
- Threat: Coverage entries rot after tests are renamed.
  Mitigation: `verifyBaselineContracts()` checks every listed success/failure test file exists.
- Threat: Static tests overstate runtime coverage.
  Mitigation: The map includes `baseline_gap` strings for app-server-dependent commands and leaves live proof to future smoke phases.
</threat_model>
