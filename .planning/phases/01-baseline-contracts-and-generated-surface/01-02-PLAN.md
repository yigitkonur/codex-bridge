<objective>
Add deterministic tests and baseline metadata proving maintainers can inspect the required machine-readable envelopes without depending on a live Codex runtime.
</objective>

<threat_model>
- Threat: The test accidentally starts a real Codex app-server or uses the network.
  Mitigation: Use isolated `CODEX_BRIDGE_PLUGIN_DATA`, fake update cache, and a fixture `PATH` containing only `node`.
- Threat: JSON-mode event commands leak raw event text into the envelope.
  Mitigation: Assert `events --json` returns metadata and does not include `[DONE]` raw event output.
- Threat: Error envelopes diverge from success envelope schema.
  Mitigation: Probe an unknown subcommand with `--json` and assert `ok:false`, `schema_version`, `error.code`, and `error.retryable`.
</threat_model>
