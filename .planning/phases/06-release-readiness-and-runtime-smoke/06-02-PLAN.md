# 06-02 Plan: Release Packaging From Source And Checksum Artifacts

## Goal

Move release packaging into a tested source script so local and GitHub release behavior are the same.

## Tasks

1. Add a release packaging script that validates the tag against `package.json`.
2. Build or reuse generated bundles, stage `skill/` under `codex-bridge/`, and remove maintainer-only docs.
3. Create `.tar.gz`, `.zip`, `SHA256SUMS`, and `RELEASE_NOTES.md`.
4. Update the release workflow to run static verification and call the packaging script.
5. Add tests that inspect generated archives and release workflow ordering.

## Deliverables

- `scripts/package-release.mjs`
- `package.json`
- `.github/workflows/release.yml`
- `test/release-readiness.test.mjs`

## Verification

- `node --test test/release-readiness.test.mjs`
- `npm run verify:static`
